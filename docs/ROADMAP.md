# ZShield 路线图

每个里程碑对应 MYS-2704 的一个子 issue（按 stage 串行）。同一时间只有一个开发里程碑在执行；UI 由技术负责人并行实现（不与开发里程碑改同一文件）。

| 里程碑 | 内容 | 关键验收 | 状态 |
|---|---|---|---|
| M0 工程骨架 + DNS 过滤 MVP | Gradle + Rust core + JNI；VpnService（仅 DNS 模式）；DNS 规则匹配 + DoH 上游 + 缓存；`scripts/build.sh`（清旧包、尺寸检查）；临时调试页 | Pixel 5 上开启后 `ads` 测试域名被拦截、正常域名可解析；APK ≤ 10 MB | ✅ 完成（PR #1，v0.0.1，APK 2.39 MB） |
| M1 订阅系统 | 订阅目录、URL/文件导入、自定义规则、条件更新、JobScheduler 周期更新、adblock-rust 引擎编译与序列化、规则统计 | 内置目录全部可下载解析；冷启动加载序列化引擎耗时与内存记录 | ✅ 完成（PR #2，v0.0.2，APK 3.96 MB） |
| M2a 完整隧道 | 用户态 TCP/IP 栈、直通转发、任意 53 端口 DNS 劫持、QUIC 拦截、ECH 剥离、DoH/DoT 绕过拦截、SNI/Host 级拦截、按应用排除、IPv6 | 浏览/视频/下载回归无断网；吞吐 ≥ 无 VPN 的 80%；性能基线 | ✅ 完成（PR #3 + IPv6 修复 PR #4，v0.0.3，APK 4.12 MB） |
| M2b HTTP 过滤管线 | adblock 引擎运行时加载与热替换、HTTP 请求模型（URL/来源/类型）、拦截与 redirect 资源、请求日志 | 明文 HTTP 广告请求被拦截；PSS ≤ 150 MB | ✅ 完成（PR #5，v0.0.4，APK 4.83 MB，空闲 PSS ≈ 143 MB） |
| M3a HTTPS 解密 | 根证书生成/导出/安装引导、按应用（浏览器名单 + 用户勾选）解密 H1/H2、网络规则与 `$removeparam`/`$removeheader`/`$csp`/`$redirect`、上游校验失败直通、握手失败自动放行 | 浏览器 HTTPS 页面路径级规则生效；钉扎应用不断网；PSS ≤ 170 MB | ✅ 完成（PR #7，v0.0.6，APK 7.42 MB；返工一次修复 12 项 h2/收尾问题） |
| M3b 外观过滤 | 元素隐藏 CSS 与 scriptlet 注入（gzip 流式、CSP nonce）、testcases.agrd.dev 等测试页得分 | `docs/EFFECTIVENESS.md` | ✅ 完成（PR #9，v0.0.9，APK 7.76 MB；返工两次：XSS 防护、大页面 flush 回归）；稳定性修复批次 1 ✅ v0.0.7；预连接误放行修复 ✅（PR #11，v0.0.9） |
| M4 保活与能耗 | 前台服务、始终开启 VPN 引导、电池优化豁免、开机/升级恢复、QS 磁贴、自检；能耗优化与测量 | DESIGN.md 第 7 节全部场景通过；`docs/PERF.md` | ✅ 完成（v0.0.10：M4a PR #12、M4b PR #13；后台空闲 PSS 76.9–79.3 MB；DESIGN §7 场景除网络切换外全部真机通过）；自检页 UI 由技术负责人实现 |
| M5 效果对标与 v0.1 | 以 AdGuard 公开测试用例与 20 站对照为对标依据（不做真机直接对比）、补齐高频不支持规则、请求日志、发布 v0.1.0 | 对比报告；Release | ✅ 完成（v0.1.0）：M5a 基线（PR #15）；试用反馈修复 v0.0.11（PR #14）；M5b 规则补齐（PR #16：有效规则 98.7%→99.9%，testcases element-hiding 0/10→5/10、extended-css 0/29→15/29，adblock-tester HTTPS 96 / 默认 68） |
| UI（技术负责人） | 首页开关与统计、过滤器、HTTPS、应用管理、设置、日志页 | 多尺寸截图、明暗主题 | 首版（首页/过滤器/请求日志/设置/排除应用/规则编辑）v0.0.5；HTTPS 设置页 ✅ v0.0.8（PR #10）；保护检查（自检/保活引导）页 ✅ v0.1.1（PR #17）；待做：请求日志分组筛选、磁贴正式图标、横屏首页 |
| 迭代 I1（MYS-2756） | testcases.agrd.dev 14 页全量复测 + 失败用例修复（网络规则类、`#@#` 例外、`$popup`/`$denyallow` 例外、默认解密名单补 LineageOS 浏览器） | 逐用例前后对比表、不允许回退、排除项归类并附证据 | ✅ 完成（PR #18，v0.1.2，APK 8.03 MB；返工 2 轮）：14 页合计 45→48/115（无页面回退）；entity `$domain`、全局 `#@#`、例外优先级、子框架拦截改空文档；后台空闲 PSS 47.4 MB；20 站无新增破版信号 |
| 迭代 I2（MYS-2786） | 请求链路正确性：`$removeparam` 非导航原地改写、`$subdocument` 请求类型语义；启动编译复用与HTTP收尾 | H1/H2上游语义14/14、真实VPN并发300/300、冷启动96/96/96及68/68/68、14页48/115无回退 | ✅ 发布批准（2026-11-15，v0.1.3，PR #34 → #28 → #19）：APK 8.07 MiB；五表86.20/88.78 MiB未达84.6，MYSWY明确允许本次发布，未修改实测结果；九表95.46 MiB。细节及限制见 EFFECTIVENESS §17–19 |
| I2后续：常驻内存与连接兼容性 | 固定规则下继续降低后台PSS；定位非目标CLOSE_WAIT与既有站点兼容问题 | 保持过滤效果；区分连接所有者、增长趋势与实际资源泄漏；同输入记录内存 | 待办：五表84.6 MiB仍为优化目标；3个非目标CLOSE_WAIT未定因；CNN/Stack Overflow开启保护异常在旧版源码也复现。不得宣称全局无泄漏或全部站点业务通过；不阻断MYSWY已明确授权的本次v0.1.3发布 |
