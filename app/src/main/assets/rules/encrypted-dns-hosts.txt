# Public encrypted-DNS endpoints (DoH / DoT), blocked when "blockEncryptedDnsBypass" is on.
#
# Why this list exists: a browser that switches to DNS-over-HTTPS resolves names outside the tunnel,
# so DNS filtering silently stops working for that app. Refusing the TLS connection to these hosts
# (and TCP/853 for DoT) forces the app back to plain DNS, which the tunnel hijacks.
#
# Our own upstreams are NOT affected: the core's outbound sockets are excluded from the tunnel with
# addDisallowedApplication, so this list never sees them. Two entries below (dns.alidns.com,
# doh.pub) *are* the default upstreams — that is intentional, so a browser cannot use them either.
#
# Format: one hostname per line, '#' comments. A listed name also matches its subdomains.
# Sources (checked 2026-11-08):
#   Google Public DNS      https://developers.google.com/speed/public-dns/docs/doh
#   Cloudflare             https://developers.cloudflare.com/1.1.1.1/encryption/dns-over-https/
#   Quad9                  https://www.quad9.net/news/blog/doh-with-quad9-dns-servers/
#   AdGuard DNS            https://adguard-dns.io/kb/general/dns-providers/
#   NextDNS                https://nextdns.io/
#   OpenDNS / Cisco        https://doc.opendns.com/
#   AliDNS (Alibaba)       https://help.aliyun.com/zh/dns/
